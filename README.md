# Git Workshop Practice & Notes

A hands-on repository containing practice files, command exercises, and workflow notes from a **Git & GitHub Workshop**, maintained by **MD-RATUL-HASAN**.

## Overview

This repository documents practical exercises covering core version control workflows, branching strategies, pull requests, and repository management.

## Topics Covered

- **Git Configuration & Setup:** User identity, default branch setup, and authentication
- **Core Daily Workflow:** Staging (`git add`), committing (`git commit`), syncing (`git pull` / `git push`), and checking status/diffs
- **Branching & Merging:** Creating feature branches, merging changes, and resolving conflicts
- **Pull Requests & Collaboration:** Opening, reviewing, and merging PRs on GitHub
- **History & Safety:** Inspecting logs, reverting commits, amending local commits, and using `.gitignore`
